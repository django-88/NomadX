# Security policy

NomadX is an adversary-emulation and red-team tool. It must only be used on
systems you own or have explicit written authorization to test.

## Reporting a vulnerability

Please use GitHub's **private vulnerability reporting** or a GitHub security
advisory rather than a public issue. Do not include:

- live C2 URLs, API tokens, AES keys, or UUIDs
- unredacted payloads or agent configs
- customer names, hostnames, or IP addresses

Include the affected component, a minimal reproduction, and the expected versus
actual behavior.

## Scope

This policy covers the NomadX source tree and its build/deployment tooling. It
does not authorize testing against third-party systems or networks.
